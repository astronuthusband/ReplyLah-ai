# ReplyLah 🇲🇾

**AI-powered WhatsApp reply assistant built for Malaysian businesses.**

ReplyLah helps business owners instantly generate natural, human-like WhatsApp replies based on customer messages — in Manglish, English, or professional tone.

---

## 🚀 Live Demo

👉 https://replylah.my

---

## 📌 Features

- 🧠 AI-generated WhatsApp replies
- 🇲🇾 Malaysian-style tone (Manglish, friendly, polite)
- 🏪 Built for real businesses (salon, F&B, tuition, etc.)
- ⚡ Instant reply generation
- 🎯 Tone control (Friendly / Professional / Super Polite)
- 📝 Business context support (pricing, hours, policies)
- 💬 WhatsApp-style UI for realistic previews

---

## 🛠️ Tech Stack

- **Next.js 15 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Groq AI API**
- **Vercel (Deployment)**
